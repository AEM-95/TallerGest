# TallerGest

Sistema multiplataforma de gestión integral para pequeños talleres de automoción.

## Descripción

TallerGest es un proyecto desarrollado por dos estudiantes del ciclo formativo de Desarrollo de Aplicaciones Multiplataforma (DAM).

Su objetivo es facilitar la gestión de las operaciones habituales de un pequeño taller de automoción.

## Funcionalidades previstas

- Gestión de clientes.
- Gestión de vehículos.
- Elaboración de presupuestos.
- Gestión de órdenes de trabajo.
- Registro de intervenciones.
- Consulta del historial de reparaciones.

## Tecnologías previstas

- Java
- JavaFX
- JPA / Hibernate
- PostgreSQL
- Maven
- Git y GitHub
